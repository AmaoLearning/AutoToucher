## 1. 产品简介

**AutoToucher** 是一款基于 Android 无障碍服务的定时自动点击工具。它可以在每天的指定时间，自动按照预设的步骤序列在屏幕上执行点击、返回、回桌面等操作，无需人工干预。

### 典型用途

- 每天定时完成特定应用的操作
- 定时领券、抢票、领取游戏奖励
- 任何需要每天在固定时间重复操作的场景

### 核心特性

| 特性 | 说明 |
|------|------|
| 定时触发 | 精确到分钟，支持多任务并行 |
| 随机延迟 | 模拟人工操作，规避风控检测 |
| 步骤序列 | 支持任意数量的有序操作步骤 |
| 开机自动恢复 | 重启手机后无需重新设置，自动恢复所有任务 |
| 无须 Root | 基于 Android 官方无障碍服务 API，合法合规 |

## 2. 安装与首次启动

### 安装 APK

1. 在手机上打开 APK 文件，按提示允许"安装未知来源应用"。
2. 安装完成后，在应用列表中找到 **AutoToucher** 并打开。

### 首次启动流程

首次启动会自动跳转到**权限授权页**。必须完成所有必要授权后，才能进入主功能界面。

## 3. 权限授权指南

AutoToucher 需要以下权限才能正常工作：

### 3.1 无障碍服务（必须）

**作用**：注入屏幕点击手势、模拟返回键/Home键。这是 AutoToucher 执行自动点击的核心能力。

**开启步骤**：

1. 点击授权页中「无障碍服务」右侧的**前往授权**按钮。
2. 系统跳转至「设置 → 更多设置 → 无障碍」。
3. 在「已下载的应用」列表中找到 **AutoToucher**，点击并开启。
4. 弹出确认对话框，点击**允许**。
5. 返回 AutoToucher，授权页显示✓表示成功。

> **小米手机额外操作**：见第 10 节专项设置，否则服务可能在后台被自动关闭。

### 3.2 精确闹钟权限（Android 12+ 必须）

**作用**：保证任务在精确时间触发，而不是被系统批量延迟执行。

**开启步骤**：

1. 点击「精确闹钟」右侧的**前往授权**按钮（Android 12 以下不显示此项）。
2. 在系统设置中找到 AutoToucher，开启「允许设置精确闹钟」。
3. 返回 AutoToucher 即自动刷新。

### 3.3 通知权限（Android 13+ 必须）

**作用**：任务执行时在通知栏显示「AutoToucher 执行中」，这是前台服务的必要条件，缺失会导致 App 崩溃。

**开启步骤**：

1. 点击「通知权限」右侧的**前往授权**按钮（Android 13 以下不显示此项）。
2. 在弹出的系统对话框中选择**允许**。

### 授权完成

所有必要权限授权完成后，点击**进入应用**按钮，进入任务列表页。

## 4. 核心概念

### 任务（Task）

一条任务代表一个「每日定时执行的操作计划」，包含：

- **触发时间**：每天在哪个时间点触发（时:分）
- **启动延迟**：触发后随机等待多少秒再开始执行
- **步骤间隔**：每个操作步骤之间默认等待的秒数范围
- **步骤列表**：按顺序执行的操作序列
- **启用状态**：该任务是否处于激活状态

### 操作步骤（Action）

每个步骤是任务中的一个具体操作，共有 4 种类型：

| 类型 | 说明 | 需要坐标 |
|------|------|----------|
| **TAP** | 点击屏幕指定位置 | ✓ 需要填写 X、Y 像素坐标 |
| **BACK** | 模拟按下返回键 | ✗ |
| **HOME** | 模拟按下 Home 键，回到桌面 | ✗ |
| **CLOSE_ALL** | 打开最近任务并清除所有后台应用 | ✗ |

### 延迟体系

```
触发时间到达
    ↓
等待「启动延迟」（随机 [min, max] 秒）
    ↓
执行步骤 1
    ↓
等待「步骤间隔」（随机 [min, max] 秒）
    ↓
执行步骤 2
    ↓
...（最后一步后不再等待）
    ↓
任务完成，自动注册明天同一时间的闹钟
```

## 5. 创建与管理任务

### 5.1 创建新任务

1. 在任务列表页，点击右下角的 **+** 按钮（浮动操作按钮）。
2. 进入任务编辑页，填写各项参数（详见下方说明）。
3. 点击右上角的**保存**图标，任务创建成功并自动注册闹钟。

### 5.2 编辑已有任务

在任务列表中，点击任意任务卡片，进入编辑页修改后保存。

### 5.3 启用 / 禁用任务

在任务卡片右侧有一个**开关（Switch）**：
- **开启**：任务将在下一个触发时间自动执行
- **关闭**：取消该任务的闹钟，不再自动执行

### 5.4 删除任务

点击任务卡片右侧的**删除图标**，在确认对话框中点击**确认**删除。删除后对应闹钟也会同步取消。

## 6. 配置操作步骤

### 6.1 添加步骤

在任务编辑页下方，点击**添加步骤**按钮，弹出步骤编辑对话框。

**步骤编辑对话框字段说明**：

**① 操作类型**  
用单选按钮选择：`TAP` / `BACK` / `HOME` / `CLOSE_ALL`

**② 坐标（仅 TAP 类型显示）**  
填写屏幕像素坐标。对话框底部会提示「当前设备分辨率：宽 × 高」供参考。  
→ 如何获取坐标，见第 9 节。

**③ 覆盖此步骤的等待时间（可选）**  
勾选后可为本步骤单独设置执行后的等待时长，覆盖任务级别的步骤间隔配置。  
适用于某些步骤需要更长等待时间（如等待 App 启动动画）的场景。

### 6.2 调整步骤顺序

每个步骤右侧有**上移 ↑** 和**下移 ↓** 按钮，点击调整执行顺序。

### 6.3 编辑 / 删除步骤

- 点击步骤右侧的**编辑图标**，重新打开步骤编辑对话框。
- 点击**删除图标**，直接删除该步骤。

## 7. 延迟参数详解

### 启动延迟（任务级）

| 参数 | 含义 | 默认值 |
|------|------|--------|
| 最小延迟（秒） | 任务开始前最少等待时间 | 0 |
| 最大延迟（秒） | 任务开始前最多等待时间 | 5 |

系统会在 `[最小, 最大]` 范围内随机取一个整数秒数作为实际延迟。设置范围可使触发时间具有随机性，更接近人工操作。

**示例**：触发时间设为 09:00，启动延迟 `[0, 120]` 秒，则实际执行时间在 09:00:00 ~ 09:02:00 之间随机。

### 步骤间隔（任务级）

| 参数 | 含义 | 默认值 |
|------|------|--------|
| 最小间隔（秒） | 两步骤之间最少等待时间 | 4 |
| 最大间隔（秒） | 两步骤之间最多等待时间 | 8 |

**建议**：步骤间隔不宜过短（建议 ≥ 2 秒），需给 App 足够的响应和渲染时间，否则下一步点击时目标界面可能还未加载完成。

### 单步骤延迟覆盖

在步骤编辑对话框中勾选「覆盖此步骤的等待时间」，可以为该步骤单独设置等待范围，优先级高于任务级间隔。

**适用场景**：
- 步骤 1 点击 App 图标后，需要等待 App 启动（建议覆盖为 `[5, 10]` 秒）
- 步骤 3 点击对应位置后，需要等待后续动画完成（建议覆盖为 `[3, 6]` 秒）

## 9. 获取屏幕坐标

TAP 步骤需要填写屏幕上目标元素的精确像素坐标。以下是获取坐标的方法：

### 方法一：Android 开发者选项（推荐）

1. 进入「设置 → 关于手机」，连续点击「版本号」7 次，开启开发者模式。
2. 进入「设置 → 开发者选项」，开启「显示触控操作」或「指针位置」。
3. 开启「指针位置」后，屏幕顶部会实时显示当前触摸点的 X、Y 坐标。
4. 用手指点击目标位置，记录显示的坐标值。
5. 记录完成后关闭「指针位置」。

### 方法二：截图标注

1. 截取目标界面的截图。
2. 用图片编辑工具（如 PS、Photopea）打开截图，将鼠标悬停在目标位置，读取像素坐标。

> **重要提示**：  
> - 坐标是**绝对像素值**，不同设备分辨率不同，在一台手机上标记的坐标**不适用于其他分辨率的手机**。
> - 任务编辑页和步骤对话框底部会显示「当前设备分辨率」，可辅助确认。
> - 若手机开启了「显示大小」缩放，实际像素坐标可能与视觉位置有偏差，建议以「指针位置」工具的实时读数为准。

## 10. 小米 / HyperOS 专项设置

小米设备（MIUI / HyperOS）对后台服务有额外管控，必须完成以下设置，否则无障碍服务会在后台自动被关闭。

### 必须配置（按顺序）

**① 允许自启动**

「设置 → 应用设置 → 应用管理 → AutoToucher → 自启动」→ **开启**

**② 关闭电池优化**

「设置 → 应用设置 → 应用管理 → AutoToucher → 省电策略」→ 改为**无限制**

或：「设置 → 电池 → 应用省电 → AutoToucher」→ 改为**无限制**

**③ 锁定后台（防止被划掉杀死）**

进入最近任务界面 → 长按 AutoToucher 的预览卡片 → 选择**锁定**

**④ 关闭 MIUI 优化（最关键，效果最好）**

「设置 → 开发者选项 → 关闭 MIUI 优化 / 系统优化」

关闭后系统将不再主动干预无障碍服务的生命周期。

### HyperOS 2.x 额外步骤

「设置 → 隐私保护 → 特殊权限 → 无障碍」→ 确认 AutoToucher 已在授权列表中。

## 11. 常见问题排查

### Q1：任务到时间没有执行

**排查步骤**：

1. 检查权限引导页，确认三项权限全部显示✓。
2. 确认任务卡片上的**开关处于开启状态**。
3. 确认任务触发时间尚未过去（若已过，下次将在明天同一时间触发）。
4. 检查精确闹钟权限（Android 12+ 需要），若显示未授权则任务只能近似时间触发。
5. 小米手机：确认完成第 10 节中的所有设置。

---

### Q2：无障碍服务开启后很快自动关闭

原因：系统后台管理将服务进程回收。

解决方案：按第 10 节完整配置，尤其是「省电策略→无限制」和「锁定后台」。

---

### Q3：点击位置偏移，没有点到目标元素

原因：坐标不准确，或手机分辨率/显示大小设置发生了变化。

解决方案：
1. 用「开发者选项 → 指针位置」重新测量目标坐标。
2. 确认手机的「显示大小」和「字体大小」设置没有变化。
3. 编辑任务，更新 TAP 步骤中的坐标值。

---

### Q4：步骤执行时目标按钮还未出现（App 未加载完）

原因：步骤间隔太短，上一步操作触发的页面跳转/加载还未完成。

解决方案：为该步骤开启「覆盖等待时间」，增大等待范围（建议至少 3~6 秒）。

---

### Q5：CLOSE_ALL 步骤没有清除所有后台

原因：不同厂商 ROM 的「清除全部」按钮文字不同，AutoToucher 使用关键词匹配（包含「清除」「清空」「全部清除」「一键清理」「clear」等）。若匹配失败，会自动降级为 HOME 操作。

解决方案：对于特殊 ROM，建议改为手动 TAP「清除全部」按钮（需要坐标）+ 配合延迟等待。

---

### Q6：应用编辑任务后，再次打开显示的仍是旧内容

原因已修复（版本 1.0 中已解决）。若仍出现，请关闭并重新打开任务编辑页。

---

### Q7：重启手机后任务失效

**原因 A**：BootReceiver 未被调用，通常是自启动权限未开启。  
→ 确认「设置 → 应用 → AutoToucher → 自启动」已开启。

**原因 B**：无障碍服务重启后未自动开启。  
→ 手机重启后需要手动确认无障碍服务仍处于开启状态（系统安全策略，部分手机在重启后会要求重新确认）。

## 12. 注意事项与限制

### 系统限制

| 限制 | 说明 |
|------|------|
| 必须手动开启无障碍服务 | Android 系统不允许 App 自动开启无障碍服务，用户必须手动授权 |
| 坐标为绝对像素值 | 换手机或调整显示大小后需重新配置坐标 |
| 精确度受系统调度影响 | Android 系统在省电模式下可能延迟触发，建议将设备保持充电状态 |
| 不支持悬浮窗操作 | AutoToucher 通过手势注入点击，而非悬浮窗，无需悬浮窗权限 |

### 使用建议

- **充电期间执行**：确保任务执行时手机处于充电状态，避免触发深度省电模式。
- **屏幕亮起无关**：无障碍服务手势注入在锁屏状态下**无法工作**。建议在执行前通过其他方式（如亮屏应用或叫醒定时器）保持屏幕亮起。
- **测试时间选择**：首次配置后，建议将任务触发时间设置为 1~2 分钟后，验证执行效果，再改为正式时间。
- **步骤间隔不宜过短**：建议最小间隔 ≥ 2 秒，确保每步操作有充分响应时间。
- **启动延迟打卡场景建议**：打卡类任务建议启动延迟设为 `[0, 300]`（5 分钟内随机），模拟人工操作更真实。

### 隐私说明

AutoToucher 所有数据（任务配置、坐标信息）仅存储在本机 Room 数据库中，不上传至任何服务器。无障碍服务仅用于注入手势，不读取任何界面内容（键盘输入、短信等）。
